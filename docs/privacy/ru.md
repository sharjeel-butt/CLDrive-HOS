# Политика конфиденциальности CLDrive Manager

**Дата вступления в силу:** 29 сентября 2026 г.
**Последнее обновление:** 29 сентября 2026 г.
**Применяется к:** CLDrive Manager версии 1.3.0 и выше

Настоящая Политика конфиденциальности описывает, как CLDrive Manager
(«Приложение», «мы», «нас», «наш») обрабатывает вашу информацию при
использовании нашего приложения для HarmonyOS.

Устанавливая или используя CLDrive Manager, вы соглашаетесь с описанными ниже
правилами.

## 1. Краткое резюме

CLDrive Manager — это файловый менеджер облачных хранилищ для HarmonyOS. Он
подключается к сторонним облачным сервисам, которые **вы** выбираете —
Microsoft OneDrive, Google Drive и Dropbox — и позволяет просматривать,
упорядочивать и передавать файлы, хранящиеся в этих сервисах.

**Мы не управляем серверами, которые хранят ваши файлы. Мы не собираем
аналитику. Мы не продаём ваши данные. У нас нет собственных аккаунтов.**

Все данные, обрабатываемые CLDrive Manager, попадают в одну из трёх категорий:

| Категория | Где хранится | Кто может видеть |
| :--- | :--- | :--- |
| **Ваши облачные файлы** | Ваш аккаунт OneDrive / Google Drive / Dropbox | Вы и сторонний провайдер |
| **Токены аутентификации** | Зашифрованная песочница приложения на вашем устройстве | Вы и приложение |
| **Настройки приложения** | Локальное хранилище на вашем устройстве | Вы |

Ничего не покидает ваше устройство, кроме API-запросов, которые вы
явно запускаете.

## 2. Информация, к которой мы получаем доступ

### 2.1 Метаданные и содержимое облачных файлов

При входе в облачный аккаунт CLDrive Manager запрашивает доступ на чтение и
запись к файлам этого аккаунта. Это позволяет приложению:

- Просматривать содержимое папок (имена файлов, размеры, метки времени)
- Скачивать содержимое файлов
- Загружать новые файлы
- Переименовывать, перемещать, копировать и удалять файлы
- Выполнять поиск по аккаунту

**Эти данные передаются напрямую между вашим устройством и облачным
провайдером.** CLDrive Manager никогда не перехватывает, не регистрирует и не
пересылает их на какие-либо наши серверы.

### 2.2 Информация об аккаунте

При входе облачный провайдер передаёт нам:

- Ваше отображаемое имя
- Ваш адрес электронной почты
- Идентификатор вашего аккаунта
- (Необязательно) Ссылку на аватар

Эта информация хранится локально на вашем устройстве для отображения
аккаунта в боковой панели и определения активного аккаунта. Она никогда
никуда не передаётся.

### 2.3 Токены аутентификации

После авторизации CLDrive Manager облачные провайдеры выдают кратковременные
токены доступа и долговременные токены обновления. Эти токены позволяют
приложению выполнять API-запросы от вашего имени без повторных запросов
разрешения.

Токены хранятся с помощью **HarmonyOS Asset Store** — защищённого
хранилища операционной системы с аппаратной поддержкой. Они
зашифрованы в состоянии покоя и недоступны другим приложениям.

## 3. Информация, которую мы НЕ собираем

CLDrive Manager **не** собирает, не передаёт и не хранит ничего из
перечисленного:

- Аналитику или статистику использования
- Отчёты о сбоях
- Идентификаторы устройств (IMEI, MAC-адрес, рекламный идентификатор)
- Данные о местоположении
- Контакты, календарь или сообщения
- Историю просмотров
- Файлы за пределами подключённых вами облачных аккаунтов

## 4. Как используется информация

| Информация | Назначение |
| :--- | :--- |
| Метаданные облачных файлов | Отображение содержимого папок, сортировка и поиск |
| Содержимое облачных файлов | Скачивание на устройство, загрузка в облако |
| Имя аккаунта и email | Определение активного аккаунта |
| Токены аутентификации | Аутентификация API-запросов к облачному провайдеру |
| Настройки приложения | Сохранение ваших настроек и журнала активности между сессиями |

## 5. Обмен данными и третьи стороны

CLDrive Manager делится данными только с облачными провайдерами, которых
**вы явно подключили**:

### Microsoft OneDrive
При входе в OneDrive ваше устройство напрямую взаимодействует с
`graph.microsoft.com` через Microsoft Graph API. Обработка ваших данных
Microsoft регулируется
[Заявлением о конфиденциальности Microsoft](https://privacy.microsoft.com/privacystatement).

### Google Drive
При входе в Google Drive ваше устройство напрямую взаимодействует с
`googleapis.com` через Google Drive API. Обработка ваших данных Google
регулируется [Политикой конфиденциальности Google](https://policies.google.com/privacy).

### Dropbox
При входе в Dropbox ваше устройство напрямую взаимодействует с
`api.dropboxapi.com` и `content.dropboxapi.com` через Dropbox API v2.
Обработка ваших данных Dropbox регулируется
[Политикой конфиденциальности Dropbox](https://www.dropbox.com/privacy).

**Никакие другие третьи стороны не получают никаких данных.** CLDrive Manager
не содержит рекламных SDK, аналитических библиотек или сервисов
телеметрии.

## 6. Хранение и срок хранения данных

### На вашем устройстве

| Данные | Расположение | Срок хранения |
| :--- | :--- | :--- |
| Токены аутентификации | Asset Store (зашифровано) | До выхода из аккаунта или удаления приложения |
| Метаданные аккаунта | Настройки песочницы приложения | До выхода из аккаунта или удаления приложения |
| История задач (последние 500 операций) | Настройки песочницы приложения | Скользящее окно на 500 элементов |
| Офлайн-файлы | Песочница приложения `filesDir` | До снятия отметки офлайн или очистки кэша |
| Промежуточные файлы загрузки | Песочница приложения `filesDir/uploads` | Удаляются при успешной загрузке, сохраняются при ошибке для повтора |
| Настройки приложения | Настройки песочницы приложения | До удаления приложения |

### У облачных провайдеров

Ваши файлы остаются в вашем аккаунте OneDrive, Google Drive или Dropbox
в соответствии с их политиками хранения. Удаление файла через CLDrive Manager
удаляет его из облачного провайдера так же, как удаление через их
нативные приложения.

## 7. Ваши права и контроль

Вы всегда полностью контролируете свои данные:

### Выход из аккаунта
Откройте боковую панель → нажмите **Выйти**. Это удаляет токены
аутентификации аккаунта из Asset Store и удаляет аккаунт из CLDrive Manager.
Ваши облачные файлы не затрагиваются.

### Удаление офлайн-файлов
Откройте **Настройки → Очистить кэш**. Это удалит все локально
кэшированные файлы и очистит реестр офлайн-файлов.

### Очистка истории задач
Откройте **Задачи** → используйте **Очистить выполненные**,
**Очистить всё** или **Принудительная очистка**.

### Отзыв доступа приложения
Вы можете в любой момент отозвать доступ CLDrive Manager к вашему облачному
аккаунту:

- **Microsoft:** [account.live.com/consent/Manage](https://account.live.com/consent/Manage)
- **Google:** [myaccount.google.com/permissions](https://myaccount.google.com/permissions)
- **Dropbox:** [dropbox.com/account/connected_apps](https://www.dropbox.com/account/connected_apps)

После отзыва CLDrive Manager больше не сможет получить доступ к вашим файлам,
даже если у него останутся токены.

### Удаление приложения
Удаление CLDrive Manager удаляет все локальные файлы, токены и настройки с
вашего устройства. После удаления ничего не сохраняется.

## 8. Безопасность

CLDrive Manager использует следующие меры безопасности:

- **OAuth 2.0 с PKCE (S256)** для OneDrive, Google Drive и Dropbox
- **Без встроенных клиентских секретов** для OneDrive и Dropbox
- **Только HTTPS** при взаимодействии с облачными провайдерами
- **Проверка параметра state** для предотвращения CSRF
- **Шифрованное хранение токенов** через HarmonyOS Asset Store
- **Автоматическое обновление токенов**, чтобы истёкшие токены не использовались повторно
- **Изолированное хранение файлов в песочнице**

Ни один способ передачи данных через интернет не является на 100%
безопасным.

## 9. Конфиденциальность детей

CLDrive Manager не предназначен для детей младше 13 лет. Мы сознательно не
собираем личную информацию от детей.

провайдера применяется политика размещения данных этого провайдера.

## 14. Заявления о соответствии

### Microsoft Graph API
Использование Microsoft Graph в CLDrive Manager соответствует
[Условиям использования API Microsoft](https://learn.microsoft.com/en-us/legal/microsoft-apis/terms-of-use).

Запрашиваемые разрешения: `Files.ReadWrite`, `User.Read`, `offline_access`.

### Google Drive API
Использование Google Drive в CLDrive Manager соответствует
[Политике использования данных пользователей API Google](https://developers.google.com/terms/api-services-user-data-policy),
включая требования ограниченного использования.

**Запрашиваемые области доступа:**

| Область | Назначение |
| :--- | :--- |
| `https://www.googleapis.com/auth/drive.file` | Создание, изменение и удаление файлов и папок, которые пользователь открывает или создаёт через CLDrive Manager |
| `https://www.googleapis.com/auth/drive.metadata.readonly` | Чтение метаданных файлов и папок для отображения файлового браузера |

### Dropbox API
Использование Dropbox API в CLDrive Manager соответствует
[Условиям использования Dropbox API](https://www.dropbox.com/developers/reference/terms).

**Запрашиваемые области доступа:** `account_info.read`,
`files.metadata.read`, `files.metadata.write`, `files.content.read`,
`files.content.write`.
