# CLDrive

**مدير ملفات سحابي موحد لنظام HarmonyOS.**

يجمع CLDrive بين OneDrive و Google Drive و Dropbox في متصفح ملفات
واحد ومتسق. أدِر كل حساباتك السحابية من تطبيق HarmonyOS أصلي واحد —
مع عمليات عبر المزودين ومصادقة PKCE آمنة وبنية قابلة للتوسع تجعل
إضافة مزود جديد مسألة كتابة فئة واحدة فقط.

**الإصدار الحالي:** 1.2.1

## ✨ الميزات

### حسابات ومزودون متعددون
- سجّل الدخول بحسابات OneDrive و Google Drive و Dropbox غير محدودة
- شجرة الشريط الجانبي تجمع الحسابات حسب المزود
- التبديل بين الحسابات بلمسة واحدة
- صورة واسم وبريد إلكتروني لكل حساب

### متصفح ملفات موحد
- عرض قائمة متسق عبر جميع المزودين
- تنقل بين المجلدات مع مسار التنقل
- بيانات الملف الوصفية: الاسم والحجم وتاريخ التعديل وأيقونة خاصة بالنوع
- التحديث بالسحب وحالات التحميل ومعالجة الأخطاء
- البحث في الحساب النشط
- امتدادات الملفات المستنتجة تلقائيًا من نوع MIME

### التحديد المتعدد والعمليات المجمعة
- اضغط مطولاً على أي عنصر لدخول وضع التحديد
- تحديد الكل / إلغاء تحديد الكل
- حذف ونقل ونسخ وتنزيل مجمّع
- حل التعارضات: تخطي الكل / الاحتفاظ بالاثنين / استبدال الكل
- شريط إجراءات التحديد بالترتيب: **نسخ · نقل · تنزيل · حذف**

### لوحة المهام
- تقدم مباشر للتحميلات والتنزيلات وعمليات النقل والنسخ والحذف
- أربع علامات تبويب: **الكل · قيد الانتظار · تم · فشل**
- قيد الانتظار تُظهر الدفعة الكاملة قبل بدء التنفيذ
- العمليات مجمعة حسب التاريخ (اليوم / أمس / تواريخ محددة)
- السجل يستمر بين الجلسات (حتى 500 مهمة حديثة)
- أشرطة تقدم لكل عملية نقل
- **إعادة المحاولة** للمهام الفاشلة (↻ لكل صف و إعادة المحاولة للكل)
- أيقونة النشاط في الشريط العلوي تعكس الحالة:
    - **أزرق** — مهمة أو أكثر قيد التنفيذ
    - **رمادي** — خامل، لا يوجد سجل
    - **أخضر** — جميع المهام نجحت
    - **أصفر** — نجاح وفشل مختلط
    - **أحمر** — جميع المهام فشلت

### الوصول دون اتصال
- علّم أي ملف كـ **متاح دون اتصال**
- تُخزَّن الملفات في صندوق التطبيق الخاص
- افتح الملفات دون اتصال بالعارض الافتراضي للنظام
- ملخص استخدام التخزين ومسح ذاكرة التخزين المؤقت في الإعدادات

### المظهر
- فاتح وداكن واستخدام إعدادات النظام
- تفضيل المستخدم محفوظ
- دعم كامل للسمة على كل شاشة، بما في ذلك WebView الخاص بـ OAuth

### آمن بالتصميم
- تدفق تفويض OAuth 2.0 مع PKCE (S256)
- لا توجد أسرار عملاء مضمنة (OneDrive و Dropbox يستخدمان PKCE نقي)
- الرموز في HarmonyOS Asset Store (مجزّأة لتجاوز حد 1024 بايت)
- تحديث تلقائي للرموز عند انتهاء صلاحيتها
- التحقق من معامل الحالة لمنع CSRF
- منتقي الملفات المتعددة ينسخ الملفات إلى صندوق مؤقت قبل التحميل، لذلك تعمل إعادة المحاولات عبر عمليات إعادة تشغيل التطبيق

## 🏗️ البنية

تم بناء CLDrive حول تجريد المزود. طبقة واجهة المستخدم لا تلمس
أبدًا API خاصًا بالمزود — بل تتحدث إلى الواجهات، ويوفر المصنع
التنفيذ الصحيح في وقت التشغيل.


العقود الرئيسية:

- **`ICloudProvider`** — واجهة موحدة يطبقها كل مزود
- **`IAuthProvider`** — عقد OAuth
- **`CloudItem`** — نموذج موحد للملف/المجلد (لا يكشف أبدًا DTOs المزود)
- **`DownloadInfo`** — URL + رؤوس لمصادقة التنزيل

يعيش كل مزود في مجلده الخاص مع **Provider** و **AuthProvider** و
**ApiClient** و **Mapper** و **Config**.

---

## 🔐 المصادقة والأمان

- **تدفق تفويض OAuth 2.0 مع PKCE (S256)** لجميع المزودين الثلاثة
- **لا أسرار عملاء** في ملفات OneDrive و Dropbox التنفيذية
- تتطلب Google سر عميل بسبب نوع عميل OAuth "Web application"
- الرموز في **HarmonyOS Asset Store**، مجزّأة بـ 900 بايت لتجاوز حد 1024 بايت
- `TokenRefresher` يتعامل بشفافية مع 401 عبر التحديث التلقائي
- التحقق من معامل الحالة يمنع CSRF
- HTTPS فقط

### سجّل تطبيقات OAuth الخاصة بك

CLDrive عميل OAuth عام وكل مستخدم يسجّل تطبيقه في لوحات المزودين
الثلاثة. هذا يُبقي كل مستخدم في تحكم كامل ببيانات اعتماده الخاصة.

**Azure (OneDrive)**
1. Azure Portal → تسجيلات التطبيقات → تسجيل جديد
2. أنواع الحسابات المدعومة: متعدد المستأجرين + حسابات Microsoft الشخصية
3. URI إعادة التوجيه: منصة الأجهزة المحمولة وسطح المكتب → `https://cl.drive/oauth`
4. الإعدادات المتقدمة → السماح بتدفقات العميل العام: **نعم**
5. الأذونات المفوّضة: `Files.ReadWrite`، `User.Read`، `offline_access`

**Google Cloud (Google Drive)**
1. Google Cloud Console → APIs & Services → بيانات الاعتماد → إنشاء عميل OAuth
2. نوع التطبيق: **Web application**
3. URI إعادة التوجيه المصرّح به: `http://127.0.0.1:8080/oauth2redirect`
4. فعّل Google Drive API

**Dropbox**
1. Dropbox App Console → إنشاء تطبيق
2. Scoped access → Full Dropbox
3. OAuth 2.0 → URI إعادة التوجيه → `https://cl.drive/dropbox-oauth`
4. الأذونات: `account_info.read`، `files.metadata.read`،
   `files.metadata.write`، `files.content.read`، `files.content.write`
