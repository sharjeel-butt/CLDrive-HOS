# CLDrive

**مدير ملفات سحابي موحّد لـ HarmonyOS.**

يجمع CLDrive بين OneDrive وGoogle Drive وDropbox في متصفح ملفات واحد ومتّسق. أدر كل حساباتك السحابية من تطبيق HarmonyOS أصلي واحد — مع عمليات عبر المزوّدين، ومصادقة PKCE آمنة، وبنية قابلة للتوسّع تجعل إضافة مزوّد جديد مجرد كتابة صنف واحد.

**الإصدار الحالي:** 1.4.0

## ✨ الميزات

### حسابات متعددة ومزوّدون متعددون
- سجّل الدخول بعدد غير محدود من حسابات OneDrive وGoogle Drive وDropbox
- شجرة الشريط الجانبي تجمّع الحسابات حسب المزوّد
- بدّل بين الحسابات بلمسة واحدة
- صورة رمزية واسم عرض وبريد إلكتروني لكل حساب
- سجّل الخروج مباشرة من صف الحساب النشط

### متصفح ملفات موحّد
- تجربة متّسقة عبر كل مزوّد
- **تخطيطات القائمة والشبكة** مع زر تبديل بنقرة واحدة في الشريط العلوي
- تنقّل بين المجلدات مع مسار تنقل قابل للنقر
- **شرائح التصفية**: الكل · الصور · الفيديو · المستندات · الصوت · أخرى
- **قائمة الترتيب**: الاسم (أ–ي / ي–أ)، الأحدث، الأقدم، الأكبر
- بيانات وصفية للملف: الاسم، الحجم، الطابع الزمني النسبي، أيقونة خاصة بالنوع
- صور مصغّرة حقيقية عندما يوفّرها المزوّد؛ وإلا شارات FileIcon
- **شارة مشترك** تعلّم الملفات والمجلدات التي لا تملكها
- السحب للتحديث، وحالات التحميل، ومعالجة الأخطاء
- البحث في الحساب النشط مع استعلامات مؤجّلة
- امتدادات ملفات تُملأ تلقائيًا مستخرجة من نوع MIME

### تحديد متعدد وعمليات دفعية
- اضغط مطولًا على أي عنصر للدخول إلى وضع التحديد
- تحديد الكل / إلغاء تحديد الكل
- حذف ونقل ونسخ وتنزيل دفعة واحدة
- حل التعارض: تخطي الكل / الاحتفاظ بالنسختين / استبدال الكل
- شريط إجراءات التحديد مرتب: **نسخ · نقل · تنزيل · حذف**

### لوحة المهام
- تقدّم مباشر لعمليات الرفع والتنزيل والنقل والنسخ والحذف
- أربع علامات تبويب: **الكل · معلّق · منجز · فشل**
- يعرض المعلّق الدفعة المصطفّة كاملة قبل بدء التنفيذ
- العمليات مجمّعة حسب التاريخ (اليوم / أمس / تواريخ محددة)
- سجل تاريخي يبقى عبر إعادة تشغيل التطبيق (حتى 500 مهمة حديثة)
- مؤشرات تقدّم حلقية لكل عنصر للعمليات الجارية
- دعم **إعادة المحاولة** للمهام الفاشلة (↻ لكل صف و إعادة محاولة الكل)
- تعكس أيقونة النشاط في الشريط العلوي الحالة:
  - **أزرق** — مهمة أو أكثر قيد التشغيل
  - **رمادي** — خامل، لا يوجد سجل
  - **أخضر** — كل المهام نجحت
  - **أصفر** — نجاح جزئي وفشل جزئي
  - **أحمر** — كل المهام فشلت

### الوصول دون اتصال
- علّم أي ملف كـ **متاح دون اتصال**
- تُخزَّن الملفات في الحماية الخاصة للتطبيق (`filesDir`)
- افتح الملفات دون اتصال بالعارض الافتراضي للنظام
- اضغط أي ملف متصل لتنزيله إلى ذاكرة معاينة مؤقتة وفتحه بخطوة واحدة
- **ذاكرة مؤقتة لكل حساب**: تُتبَّع الملفات المخزّنة مؤقتًا لكل حساب بشكل منفصل
- امسح الذاكرة المؤقتة لكل حساب من الشريط الجانبي؛ يُعرض الحجم والعدد مباشرة

### نظرة عامة على التخزين
- تعرض بطاقة التخزين في الشريط الجانبي حصة السحابة للحساب النشط
  - OneDrive: حصة `/me/drive`
  - Google Drive: `storageQuota`
  - Dropbox: `get_space_usage`
- يتحول شريط الحصة إلى الأحمر عند تجاوز الاستخدام 85%
- يعرض قسم الذاكرة المؤقتة دون اتصال عدد العناصر والحجم الإجمالي للحساب النشط

### المظهر
- فاتح، داكن، واستخدام إعدادات النظام
- تفضيل مستخدم محفوظ
- دعم كامل للسمة في كل الشاشات، بما في ذلك OAuth WebView
- مجموعة أيقونات SVG كاملة ترث لون السمة في كل الواجهة

### آمن بالتصميم
- تدفق تفويض OAuth 2.0 مع PKCE (S256)
- لا أسرار عملاء مضمّنة في التطبيق (OneDrive وDropbox يستخدمان PKCE خالصًا)
- تُخزَّن الرموز المميزة في HarmonyOS Asset Store (مقسمة لتجاوز حد 1024 بايت)
- تحديث تلقائي للرموز المميزة عند انتهائها
- التحقق من معامل الحالة لمنع CSRF
- ينسخ منتقي الملفات المتعدد الملفات إلى منطقة تجهيز معزولة قبل الرفع، لذا تعمل إعادة المحاولة عبر إعادة تشغيل التطبيق

### قريبًا
- **WebDAV** — Nextcloud وownCloud وSynology وأي خادم WebDAV
- **Amazon S3** — تخزين كائنات متوافق مع S3
- **Box** — تخزين Box السحابي

تظهر هذه في منتقي المزوّدين مع علامة "قريبًا".

## 🏗️ البنية

CLDrive مبني حول تجريد المزوّد. طبقة الواجهة لا تلمس أبدًا واجهة API خاصة بمزوّد — بل تتحدث إلى واجهات، ويوفّر المصنع التنفيذ الصحيح في وقت التشغيل.

```
UI (pages/components)
  → ViewModels
    → CloudProviderFactory
      → ICloudProvider implementations
        → Core (HttpClient, TokenStorage, PkceHelper)
```

العقود الرئيسية:

- **`ICloudProvider`** — واجهة موحّدة ينفّذها كل مزوّد
- **`IAuthProvider`** — عقد OAuth
- **`CloudItem`** — نموذج ملف/مجلد موحّد (لا يكشف أبدًا DTOs الخاصة بالمزوّد)
- **`DownloadInfo`** — URL + رؤوس لمصادقة التنزيل

يعيش كل مزوّد في مجلده الخاص مع **Provider** و**AuthProvider** و**ApiClient** و**Mapper** و**Config**.

## 🔐 المصادقة والأمان

- **تدفق تفويض OAuth 2.0 مع PKCE (S256)** لجميع المزوّدين الثلاثة
- **لا أسرار عملاء** في ثنائيات OneDrive وDropbox (عملاء PKCE عموميون)
- يتطلب Google سر عميل بسبب نوع عميل OAuth لتطبيق الويب
- تُخزَّن الرموز المميزة في **HarmonyOS Asset Store**، مقسّمة عند 900 بايت لتجاوز حد 1024 بايت لكل قيمة
- يتعامل `TokenRefresher` بشفافية مع 401 عبر التحديث التلقائي
- التحقق من معامل الحالة يمنع CSRF
- اتصال HTTPS فقط

## 📦 البدء

### المتطلبات الأساسية
- DevEco Studio 26.0.0 أو أحدث
- HarmonyOS API 26 SDK
- حساب مطوّر Microsoft أو Google أو Dropbox

### سجّل تطبيقات OAuth الخاصة بك

CLDrive عميل OAuth عمومي ويسجّل كل مستخدم تطبيقه الخاص في لوحات المزوّدين الثلاثة. هذا يبقي كل مستخدم متحكمًا بالكامل في بيانات اعتماده.

**Azure (OneDrive)**
1. Azure Portal → App registrations → New registration
2. أنواع الحسابات المدعومة: متعدد المستأجرين + حسابات Microsoft الشخصية
3. Redirect URI: نظام أساسي للجوال وسطح المكتب → `https://cl.drive/oauth`
4. الإعدادات المتقدمة → Allow public client flows: **نعم**
5. الأذونات المفوّضة: `Files.ReadWrite`، `User.Read`، `offline_access`

**Google Cloud (Google Drive)**
1. Google Cloud Console → APIs & Services → Credentials → Create OAuth client
2. نوع التطبيق: **Web application**
3. Redirect URI المصرّح به: `http://127.0.0.1:8080/oauth2redirect`
4. فعّل Google Drive API

**Dropbox**
1. Dropbox App Console → Create app
2. وصول محدّد النطاق → Full Dropbox
3. OAuth 2.0 → Redirect URIs → `https://cl.drive/dropbox-oauth`
4. الأذونات: `account_info.read`، `files.metadata.read`، `files.metadata.write`، `files.content.read`، `files.content.write`
