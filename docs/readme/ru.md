# CLDrive

**Единый файловый менеджер облачных хранилищ для HarmonyOS.**

CLDrive объединяет OneDrive, Google Drive и Dropbox в один
согласованный файловый браузер. Управляйте всеми своими облачными
аккаунтами из одного нативного приложения HarmonyOS — с
кросс-провайдерными операциями, безопасной аутентификацией PKCE и
расширяемой архитектурой, позволяющей добавить нового провайдера, написав
всего один класс.

**Текущая версия:** 1.2.1

## ✨ Возможности

### Мульти-аккаунт, мульти-провайдер
- Вход с неограниченным числом аккаунтов OneDrive, Google Drive и Dropbox
- Дерево в боковой панели с группировкой по провайдерам
- Переключение между аккаунтами одним касанием
- Аватар, отображаемое имя и адрес электронной почты для каждого аккаунта

### Единый файловый браузер
- Единообразный вид списка для всех провайдеров
- Навигация по папкам с цепочкой навигации
- Метаданные файла: имя, размер, дата изменения, значок типа
- Обновление перетаскиванием, состояния загрузки и обработка ошибок
- Поиск по активному аккаунту
- Автоматические расширения файлов на основе MIME-типа

### Множественный выбор и пакетные операции
- Долгое нажатие на элемент для входа в режим выбора
- Выбрать все / Снять выделение
- Пакетное удаление, перемещение, копирование и скачивание
- Разрешение конфликтов: Пропустить всё / Сохранить оба / Заменить всё
- Панель действий в порядке: **Копировать · Переместить · Скачать · Удалить**

### Панель задач
- Прямой прогресс для загрузок, скачиваний, перемещений, копирований и удалений
- Четыре вкладки: **Все · Ожидающие · Выполненные · Ошибки**
- Ожидающие показывает всю очередь до начала выполнения
- Операции сгруппированы по дате (Сегодня / Вчера / конкретные даты)
- История сохраняется между сессиями (до 500 последних задач)
- Полосы прогресса для каждой передачи
- **Повтор** для неудачных задач (per-row ↻ и Повторить всё)
- Значок активности в верхней панели отражает состояние:
    - **Синий** — задачи выполняются
    - **Серый** — простой, нет истории
    - **Зелёный** — все задачи успешны
    - **Жёлтый** — смешанный успех и ошибки
    - **Красный** — все задачи завершились ошибкой

### Офлайн-доступ
- Отметить любой файл как **Доступен офлайн**
- Файлы хранятся в приватной песочнице приложения
- Открытие офлайн-файлов стандартным системным просмотрщиком
- Сводка использования хранилища и очистка кэша в Настройках

### Внешний вид
- Светлая, тёмная темы и Использовать системные настройки
- Сохраняемая пользовательская настройка
- Полная поддержка темы на каждом экране, включая OAuth WebView

### Безопасность по дизайну
- OAuth 2.0 Authorization Code flow с PKCE (S256)
- Отсутствие встроенных клиентских секретов (OneDrive и Dropbox используют чистый PKCE)
- Токены в HarmonyOS Asset Store (с разбиением для обхода лимита 1024 байта)
- Автоматическое обновление токенов при истечении
- Проверка параметра state для предотвращения CSRF
- Мультифайловый выбор копирует файлы в песочницу перед загрузкой — повторы работают между сессиями

## 🏗️ Архитектура

CLDrive построен вокруг абстракции провайдера. Слой UI никогда не
обращается к специфичным для провайдера API — он работает с интерфейсами,
а фабрика предоставляет нужную реализацию во время выполнения.


Ключевые контракты:

- **`ICloudProvider`** — единый интерфейс, реализуемый каждым провайдером
- **`IAuthProvider`** — контракт OAuth
- **`CloudItem`** — единая модель файла/папки (никогда не выставляет DTO провайдера)
- **`DownloadInfo`** — URL + заголовки для авторизации скачивания

Каждый провайдер живёт в своей папке с **Provider**, **AuthProvider**,
**ApiClient**, **Mapper** и **Config**.

---

## 🔐 Аутентификация и безопасность

- **OAuth 2.0 Authorization Code flow с PKCE (S256)** для всех трёх провайдеров
- **Без клиентских секретов** в бинарниках OneDrive и Dropbox
- Google требует клиентский секрет из-за типа клиента OAuth "Web application"
- Токены в **HarmonyOS Asset Store**, разбитые по 900 байт для обхода лимита в 1024 байта
- `TokenRefresher` прозрачно обрабатывает 401 с авто-обновлением
- Проверка параметра state предотвращает CSRF
- Только HTTPS

## 📦 Начало работы

### Предварительные требования
- DevEco Studio 26.0.0 или новее
- HarmonyOS API 26 SDK
- Аккаунт разработчика Microsoft, Google или Dropbox

### Зарегистрируйте свои OAuth-приложения

CLDrive — публичный OAuth-клиент, и каждый пользователь регистрирует
своё приложение в трёх консолях провайдеров. Это оставляет каждого
пользователя в полном контроле над своими учётными данными.

**Azure (OneDrive)**
1. Azure Portal → Регистрация приложений → Новая регистрация
2. Типы поддерживаемых учётных записей: Мультитенантные + личные учётные записи Microsoft
3. URI перенаправления: платформа "Мобильные и классические приложения" → `https://cl.drive/oauth`
4. Дополнительные параметры → Разрешить потоки публичного клиента: **Да**
5. Делегированные разрешения: `Files.ReadWrite`, `User.Read`, `offline_access`

**Google Cloud (Google Drive)**
1. Google Cloud Console → APIs & Services → Учётные данные → Создать OAuth-клиент
2. Тип приложения: **Веб-приложение**
3. Авторизованный URI перенаправления: `http://127.0.0.1:8080/oauth2redirect`
4. Включите Google Drive API

**Dropbox**
1. Dropbox App Console → Создать приложение
2. Scoped access → Full Dropbox
3. OAuth 2.0 → URI перенаправления → `https://cl.drive/dropbox-oauth`
4. Разрешения: `account_info.read`, `files.metadata.read`,
   `files.metadata.write`, `files.content.read`, `files.content.write`
