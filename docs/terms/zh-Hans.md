## 1. CLDrive 是什么

CLDrive 是适用于 HarmonyOS 的**客户端云文件管理器**。它连接到
**您**选择的第三方云存储服务——Microsoft OneDrive、Google Drive
和 Dropbox——让您代表自己浏览、整理、上传、下载和管理这些服务中的
文件。

**CLDrive 不运营任何服务器。** 它不存储您的文件，没有自己的用户
账户，也不是云存储提供商。

## 2. 您的云账户

您必须拥有通过本应用连接的云服务提供商的有效账户。您对这些服务的
使用受其自身条款和政策的约束，您同意遵守这些条款和政策。

CLDrive 与 Microsoft、Google 或 Dropbox 无关联、无背书关系，
也不受其赞助。

## 3. 您的责任

您负责：

- 保护您的设备和云服务凭据的安全
- 确保您有权访问和修改通过本应用处理的任何文件
- 遵守适用法律和云服务提供商的条款
- 在共享或受损设备上使用本应用造成的任何后果

## 4. 可接受的使用

您同意不将本应用用于：

- 访问您不拥有或无权访问的文件或账户
- 违反任何法律或第三方权利
- 传播恶意软件或有害内容
- 规避任何云服务提供商或设备的安全或访问控制

## 5. 开源

CLDrive 是开源的。源代码位于
[github.com/sharjeel-butt/CLDrive-HOS](https://github.com/sharjeel-butt/CLDrive-HOS)，
并受该仓库中的许可证约束。您对源代码的使用受该许可证约束。本条款
约束您对编译后应用程序的使用。

## 6. 第三方服务

CLDrive 与 Microsoft、Google 和 Dropbox 的 API 进行交互。这些服务
的可用性、功能及数据处理实践不在我们的控制范围内，并受其自身条款
和隐私政策约束。

如果云服务提供商更改其 API、撤销访问权限或停止服务，本应用可能会
在无通知的情况下停止为该提供商工作。

## 7. 无担保

本应用按**"原样"**和**"可用"**提供，不提供任何形式的明示或默示
担保，包括但不限于对适销性、特定用途适用性和不侵权的担保。

我们不保证本应用无错误、不中断，也不保证不会发生数据丢失、损坏或
意外泄露。您使用本应用的风险由您自行承担。

- 数据丢失、损坏或意外披露

CLDrive 不会在我们控制的任何服务器上收集、传输或存储您的数据。
有关本应用如何处理身份验证令牌和文件内容的详细信息，请参阅

我们可能随时更新、修改或停止本应用，恕不另行通知。我们也可能不时

## 11. 终止

您可以随时停止使用本应用并卸载。无需关闭账户——卸载会从您的设备
中删除所有本地数据、令牌和偏好设置。

我们可以随时终止或限制对本应用的访问，但鉴于本应用是客户端且开源
